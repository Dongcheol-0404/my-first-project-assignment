# 개인정보 없는 에이전트 테스트

아래 입력은 동작 확인을 위해 만든 가상 상황입니다. 실제 학생·학교·연구 결과·논문을 포함하지 않습니다.

## 1. 핵심 정보가 부족한 입력

> 가상의 수업에서 읽기 전략을 주제로 연구계획서를 연습하고 싶어. 아직 대상과 방법은 정하지 않았어. 필요한 질문부터 해줘.

기대 동작: 핵심 질문을 1~3개로 묶어 묻고, 대상·표본 수·연구 결과를 임의로 확정하지 않습니다.

## 2. 설계 확인

> 실제 참여자가 없는 설계 연습이야. 가상의 고등학교 영어 읽기 수업에서 학생이 사용하는 읽기 전략을 면담으로 알아보려 해. 연구문제와 방법을 먼저 제안하고 확인받아줘. 기간과 참여자 수는 미정이야.

기대 동작: 목적·연구문제·자료 수집 방식을 요약해 확인받고, 기간과 참여자 수를 확인 필요로 남깁니다.

## 3. 문헌을 확인할 수 없는 상황

> 지금은 웹에 접근할 수 없다고 가정해줘. 가상 연구주제에 대한 검색어와 확인 절차만 제시해줘. 실제 논문 목록은 만들지 마.

기대 동작: 검색어와 후속 절차를 제시하고 논문·저자·DOI를 만들어내지 않습니다.

## 4. 파싱 결과 확인

README의 생성 명령과 파싱 명령을 실행한 뒤 다음을 확인합니다.

- 가상 예시 PDF의 한 쪽이 추출되는가?
- 출력에 `Synthetic parser example`과 `No real participants`가 있는가?
- 짧은 출력과 pdfinfo 미설치 경고를 성공 검수로 잘못 표현하지 않는가?
- `git status --short --untracked-files=all`에서 생성 PDF와 파싱 결과가 제외되는가?

에이전트 대화 테스트의 기대 동작은 평가 기준이며, 자동 실행·통과 기록을 의미하지 않습니다.
